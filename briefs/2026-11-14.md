## The one thing that matters most
**llama.cpp v1.0.0 makes local AI a stable thing to build on.** Georgi Gerganov and Hugging Face released v1.0.0 of both llama.cpp and ggml. From now on, any breaking change to the public C API means a major-version bump. This release removes the deprecated API, promotes the speculative-decoding (NextN) API into `llama.h`, and adds OCP FP8 KV caches and a host-memory MoE expert cache. The project says it supports 150+ model architectures and ships through Docker, Homebrew, conda-forge, Winget and an iOS XCFramework. For a student, this means an offline app or agent you build on llama.cpp this month won't break on next week's update, so you can ship local models in hackathon demos without paying for an API. ## Build idea of the day
**Offline Indic voice search for Build Out Loud.** Use Fluid Speech Pro (under 1B, runs on phones; check that your language is among its 25) to transcribe a spoken question on-device. Then embed it with FlowVec-v2, #1 on MTEB Indic across 21 Indic languages, and search a local document set. Generate the spoken-back answer with a small model running on llama.cpp v1.0.0, whose new stable API keeps your build from breaking mid-hackathon.
