## The one that matters most
**Andrej Karpathy built HackerTube, a YouTube clone made only of videos Hacker News users recommended, in about 2 hours. He did it just by talking to Claude Code (Opus 5.5).** Claude downloaded every HN comment, used Sonnet to filter out spam, and boiled 40K recommending comments down to 6,454 videos across 150 topics. It then built the site, and deployed and hardened it on a VPS. Karpathy's only manual steps were getting a YouTube API key, starting the VPS and buying the domain. He says he no longer reads or writes code himself. For a student, this is the template: pick a data source you trust, have an agent clean it, and ship a small product on top. He also publishes the site's data so your agent can build its own version. 850 points and 271 comments on Hacker News. [post](https://karpathy.bearblog.dev/hacker-tube/) · 31 Oct · [HN](https://news.ycombinator.com/item?id=50319510) · 01:26

### Security, safety and data
- Parameter Labs showed that opening a ChatGPT share link could run the attacker's JavaScript inside your signed-in session. That code could read your private chats and act as you. The chain went through the MathLive graph keyboard and HTML Preview, then used a YouTube endpoint to get past the content security policy. OpenAI fixed it on 26 Oct and paid a $5,000 bounty. It's a great case study if you're building sandboxed previews or "artifacts" into an app. 308 points on HN. [write-up](https://www.parameter.ai/labs/we-found-a-gap-at-openai) · [HN](https://news.ycombinator.com/item?id=50314699) · 16:00, 31 Oct · [Simon Willison's explainer](https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/) · 04:45
- Anthropic is extending its hidden word-choice watermark to Claude Mythos 5, Opus 4.7, Opus 4.6 and Sonnet 4.6. On Opus 4.6 and Sonnet 4.6, though, the mark only applies when temperature, top_p and top_k stay at their defaults. If you rely on it for compliance (Anthropic points to the EU AI Act's December deadline), don't touch those settings. A detection API is in private preview. [The Decoder](https://the-decoder.com/anthropics-watermark-rollout-leaves-a-loophole-on-two-older-claude-models/) · 00:50
- From 29 Nov, OpenAI will train on Daybreak Blue cybersecurity session data that used to be off-limits. After pushback, it promised a separate opt-out. If you use OpenAI's security tools on research you care about, look for that opt-out. [The Decoder](https://the-decoder.com/openai-plans-to-train-models-on-daybreak-blue-cybersecurity-session-data-that-was-previously-off-limits/) · 22:08, 31 Oct

## Benchmarks and leaderboards
- **A team of five 27B models beat a frontier model on hard coding problems.** Memdoor rebuilt the GVS5H method: five Qwen3.8-27B roles (planner, two ideators, solver, manager) plus a repair worker, which pass notes to each other only as files on disk.
