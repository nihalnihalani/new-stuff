## The one thing that matters most
**Google is handing out the multi-agent setup it uses on open research problems.** A Google Research post describes Antigravity's /teamwork. It runs agents in parallel, checks their answers with "falsifiers" (the Lean 4 proof checker, unmodified test suites, simulators), and gives each sub-agent only the files and tools it needs so long runs don't lose track. Google says it used this with Gemini 4 models to prove the Courtade–Kumar conjecture, rewrite the rest of the Zircon kernel into about 800,000 lines of safe Rust, and make a Rust port of the libgav1 video decoder 20–30% faster than the original C++. /teamwork and /boost are in Antigravity today, Deep Review gives two free calls a week, and 10,000 academic researchers can apply for six months of the top tier for free. For a student, the useful takeaways are the pattern (generator + independent verifier + small, scoped context per agent) and the free access if you qualify. [Google Research blog](https://research.google/blog/advancing-science-engineering-with-antigravitys-teamwork-feature/) · 13 Nov · [HN discussion](https://news.ycombinator.com/item?id=50496811) · 18:50, 14 Nov, 174 points

## Build idea of the day
**An injection-proof "do my errands" agent for Agent Stack 48 (18–20 Dec, online).** Build it on the OpenWorker Harness SDK with per-action approvals. Pass every web page, email or document through IBM's Granite 4.1 LLMON 8B preview first, so instructions hidden in untrusted content get tagged as data, not commands. Use planning-with-files to keep the agent's plan alive across a 48-hour run, and use the generator-plus-verifier split from Google's /teamwork post: one agent acts, a second checks each result against the user's goal. For the demo, run Microsoft's PyRIT against it live to show the injection attacks failing.
